## Default loop

1. Load catalog + brand pack + channel matrix.
2. If the ask is “make it like that” and the reference is missing → HOLD and intake first.
3. Frame → ground → direction → produce → critique → verify (`AGENTIC_DESIGN_LOOP`).
4. Local gate, then draft PR. Preview inspect before un-draft.
5. `#social-approvals` before any public post.
