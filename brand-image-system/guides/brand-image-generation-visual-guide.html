A federated design framework indexing all generated visual assets across 10 brand satellites. Built to eliminate duplicates and coordinate multi-agent media output.

The Core Mandate

No Artifact, No Claim.

Every single visual asset must be explicitly written to disk, scored, and logged in the CSV ledger. We do not approve "conceptual runs" or undocumented files. Base images are generated text-free; typography and UI schemas are rendered deterministically using Pillow or browser captures.

Tool Lane Routing

We leverage Codex image_gen and Antigravity generate_image for high-craft still base frames, and Grok CLI for motion and video jobs. Hermes batch loops are reserved for reflection passes and structured analysis once credential paths are validated.
