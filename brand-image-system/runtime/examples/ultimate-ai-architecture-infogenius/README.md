# Ultimate AI architecture — Infogenius pilot

This is the first reusable pilot for `infogenius-social.v1`. It combines a researched bounded-system model, a generated tactile source illustration, exact deterministic annotation, a 4:5 reference plate, and a five-slide mobile carousel.

## Release surfaces

- `masters/frank-omega-systems-atelier-hero.png` — 1672 × 941 FrankX editorial hero with locked FRANK-Ω identity and exact overlay.
- `release/hero/frank-omega-systems-atelier-1672x941.webp` — optimized production hero.
- `masters/master.png` — 1440 × 1800 downloadable reference plate.
- `crops/social-1080x1350.png` — 1080 × 1350 feed export.
- `crops/carousel/01-cover.png` through `05-ecosystem-map.png` — primary no-tap mobile social release.
- `accessibility/long-description.md` and `text-equivalent.md` — non-visual equivalents.

The dense one-sheet is intentionally a save/open artifact. The carousel is the primary release when body copy must be readable in a 360-pixel viewport.

## Research and semantic contract

- `sources.json` stores current official lab, protocol, OSS runtime, brand, and social-platform sources checked on 21 August 2026.
- `claim-ledger.json` stores every material architecture recommendation and its visual encoding.
- `semantic-model.json` defines the bounded-system nodes, relationships, controls, feedback, and separate provider/protocol/runtime lenses.
- `template-data.json` contains only exact public copy, placements, source identifiers, and identity routes.

The architecture does not rank model providers. Provider ecosystems sit behind one gateway; MCP, A2A, and agent runtimes are shown in distinct layers because they are not comparable products.

## Identity and mascot policy

- FRANK-Ω is the owned, locked FrankX protagonist. The hero uses the canonical `frank-omega-hero-v1.png` and `frank-omega-thinking-v1.png` references; a generic replacement robot is prohibited.
- Exact first-party OpenAI, Google Gemini, and Mistral assets are used as unmodified identity accents from recorded official sources.
- Anthropic, Meta Llama, and xAI use exact plain text because a suitable public asset could not be verified or downloaded in this run.
- Mistral calls the pixel cat an **emblem**. This pilot does not relabel it as an official mascot.
- The specialist figures in the source illustration are original editorial archetypes. They are not lab mascots or public figures.

Use the commands in `../../templates/infogenius-social/README.md`. The one-sheet renderer and carousel renderer consume the same validated `template-data.json` contract.
