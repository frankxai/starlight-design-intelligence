## Thesis

Model choice matters. The durable advantage is orchestration, context, trusted action, recovery, and evaluation.

## Architecture components

| Component | Function |
| --- | --- |
| Model gateway | Routes by capability, risk, latency, cost, and modality. |
| Agent control plane | Declares roles, routes, handoffs, budgets, permissions, and stop conditions. |
| Multi-agent workshop | Coordinates a supervisor, specialists, and reviewer through explicit contracts. |
| Context and memory | Retrieves trusted context and scopes and persists memory deliberately. |
| Capability mesh | Exposes typed tools, APIs, data, code, and retrieval with least privilege. |
| Durable runtime | Owns state, retries, checkpoints, queues, fallback, and compensation. |
| Trust and human approval | Applies policy, identity, scoped action, approval gates, and audit evidence. |
| Evals and observability | Traces quality, cost, latency, failures, regressions, and incidents. |

## Interoperability

- MCP connects tools and context.
- A2A connects independent agents.
- Microsoft Agent Framework, LangGraph, and CrewAI are runtime choices for explicit workflows, state, durability, memory, human control, and observability.
