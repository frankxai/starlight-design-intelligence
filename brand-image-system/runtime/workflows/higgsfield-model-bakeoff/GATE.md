# Gate

## GO

Proceed only when all are true:

- The brand, audience, surface, visual role, and source brief are explicit.
- Deterministic-first alternatives were considered and generation is earned.
- The model job types are confirmed against the live CLI.
- PP returns `allow` or `bounded` for the generation and visual-QA workload.
- CLI authentication, account balance, and every model cost are available.
- The account transaction window is quiet; no other recent process is spending the shared balance.
- The predicted total is within the job cap and minimum post-run balance.
- The ledger and output directory are writable.
- The shared Higgsfield execution lock is available.
- No candidate requires an unapproved likeness, identity dataset, confidential source, or protected IP.

## NO-GO

- PP returns `hold`.
- Unlimited is inferred from plan marketing rather than the selected web model badge.
- Live cost or account truth is unavailable.
- Another process has spent from the account inside the configured quiet window.
- The only path is above the approved cap.
- The job expects the model to render exact public text, claims, metrics, citations, diagrams, or UI.
- A public action, recurring schedule, account mutation, or brand-identity decision is implied.

## Escape Hatch

Record `blocked` with the exact failed gate and the smallest human decision or external-state change needed. Do not silently downgrade evidence requirements.
