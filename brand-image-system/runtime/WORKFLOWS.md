# Workflows (All Formats)

Core reusable workflows for every brand.

- social-static: Posts, quotes, proof. Hybrid premium creative + deterministic.
- social-carousel: LinkedIn/IG documents.
- website-hero: Landing first fold.
- website-header: Section banners.
- infographic: Systems, diagrams, architectures (strong premium model support for insightful text).
- og-image: Social previews.
- product-proof: Real captures.
- product-cover: Form-specific cover masters inside a founder-approved identity territory with deterministic public copy.
- product-launch-kit: One approved master expanded into website, social, proof, and delivery assets.
- deck-slide, motion-source-frame, etc.
- **arcanea-codex-encyclopedia:** Arcanea world rail — approved territory + canon card → controlled premium-model benchmark → inspected still + optional I2V → independent critique → human decision. OS: `arcanea-ai-app/.arcanea/image-lab/ARCANEA_VISUAL_OS_OPERATING_MODEL.md`.

Each workflow declares routes, outputs, QA, and approval. Load the active taste constitution first. Glass, grain, glow, dark mode, motion, and any named model are optional choices, never default taste. A diagnostic score makes a candidate eligible for human review; it cannot approve the work.
