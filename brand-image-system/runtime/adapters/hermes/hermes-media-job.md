# Hermes Media Job Workflow

Hermes should:
1. Resolve the canonical product, brand pack, product form, release state, and exact copy.
2. Create the `media-job.json` using the template.
3. Probe the current generation route and record its capability receipt. A reasoning model name is not an image-model receipt.
4. Generate source material only when the asset tier and form justify it.
5. Render canonical logos, public text, diagrams, UI, and crops deterministically.
6. Inspect actual exports and record the six 5-point dimension scores.
7. Update the experiment ledger and choose ship, iterate, restart, or blocked.
8. Feed only inspected outcomes back into Hermes memory.

Do not use the former `hermes -p arcanea` pattern. Named profiles were never verified as part of the image runtime contract. Run the job from the canonical project with the default Hermes environment, or use a project context that the operator has explicitly verified.
