# Image generation field lab — September 9, 2026

Status: documentation draft for review. Snapshot: 19 generated outputs; 144 proposed cases. No new brand identity or website publication is approved by this report.

This qualitative pilot studies whether image generation can preserve subjects, follow local edits, deliver usable files, differentiate brands, and support practical creative work. It follows the Images 2.5 announcement, but uses a built-in tool that does not expose its exact backend model. The outputs cannot establish named Images 2.5, Flare, or Sunburst performance.

## Evidence boundary

OpenAI announced Images 2.5 on September 8, including reference and editing improvements. Those are vendor claims, distinct from this pilot's observations. Consult the [announcement](https://openai.com/index/introducing-chatgpt-images-2-5/) and [official prompting guide](https://developers.openai.com/api/docs/guides/image-prompting) for current product guidance.

The execution interface accepted prompts and image references. It exposed no model selector, quality control, seed, or billing control. Requested aspect ratios were prompt intent; delivered dimensions were measured. Backend ID and billed cost remain unknown, not zero. Recorded wall-clock durations are workflow observations, not controlled model latency measurements.

The working evidence contains exact prompts, source roles, output hashes, dimensions, inspections and failed attempts. This sanitized documentation does not copy private filesystem paths, internal task identifiers, raw operational ledgers, or unreleased character reference images. A public sample release must attach the selected actual outputs and permitted references; this report alone is not a reproducible image package.

## Failures first

| Question | Observed pilot evidence | Limit |
|---|---|---|
| Does a local edit preserve other regions? | One edit removed two unwanted wall diagrams. A separate visual reviewer found changed rug texture/pattern and apparent shelving differences. | Requested deletion succeeded; strict preservation failed. No pixel-exact result. |
| Does requested transparency reach the file? | Three runs of the same Starlight wordmark prompt returned decoded RGB files without alpha. | 0/3 alpha-compliant exports in this tiny built-in-route sample; not a model-wide transparency rate. |
| Does complete-subject framing hold? | A Worldtree Deer canopy was clipped. A generated reframe restored the whole canopy but still missed the requested top margin. | Composition improved; terrain was regenerated. This was not a deterministic crop. |
| Does a repeated ensemble remain exact? | Three runs retained five recognizable role families, but changed instrument geometry/poses and repeatedly introduced diagrams or tight edge clearance. | Role resemblance is not exact identity preservation. |
| Does a logo prompt produce an identity? | Four main-brand wordmarks were readable on manual inspection. Two serif directions were too similar; spacing and distinctiveness needed work. | Raster concepts are not editable vector masters or approved brands. |
| Does changing typographic direction solve the brief? | A later FrankX sans direction separated it from Arcanea but introduced a stencil-like X cut despite the contrary instruction. | Improvement on one criterion can coincide with failure on another. |
| Does process imagery follow the requested structure? | A creator-workshop illustration retained a folded-rim motif across media, but added a vessel and occupied intended copy space. | Attractive narrative does not establish exact object count or placement compliance. |
| Does generated text match supplied copy? | One typography test appeared to preserve supplied words and accents on manual review. | No OCR study or repeatability evidence. The prompt itself contradicted its enumerated block count. |

The typography prompt asked for six blocks while specifying seven. The output included the seven enumerated blocks. Count this as a prompt defect, not a clean instruction-following result.

## Source truth before visual fidelity

A preliminary source audit found character files whose contents did not match their names. This is a source-binding defect. An image model can preserve a supplied image and still produce the wrong project result if the supplied reference is wrong. Dormant asset mismatches do not establish a live-site defect without checking the actual route binding.

Arcanea's ratified broad forms include Laeylinn as Worldtree Deer and Veloura as Phoenix-Serpent. A generated palette, face, costume, anatomy detail, or setting remains an interpretation. New Guardian portraits cannot be counted as reference-preservation tests without approved appearance anchors. Starlight operational identities must not be conflated with similarly named fictional institutions or unapproved public personas.

## Review and measurement

Separate four questions: correct source, requested change, protected-detail stability, and usefulness at the final surface. A beautiful result cannot compensate for a wrong identity or missing file property.

The maker inspected outputs. A separate agent from the same provider visually reviewed outputs 01–11 and identified collateral changes. A different-provider reviewer critiqued the methodology from text only; it did not inspect the images. These are different forms of review and must remain labeled.

For subsequent controlled work, hold source, prompt, requested dimensions and selectable settings constant. Repeat cells, randomize review order, retain every attempt, and report accepted/attempted counts. Measure human correction time and cost per accepted asset only when those quantities are actually recorded. Record unknown values as null.

Next priorities:

1. Repeat a bounded edit and inspect requested and protected regions separately.
2. Test transparency by decoding the file and compositing against contrasting backgrounds.
3. Establish one approved character reference, then test profile, action and occlusion before expanding the roster.
4. Resolve vector geometry and small-size behavior for selected wordmark directions.
5. Run an explicitly identified API route if comparing named models is the objective.

No conversion lift, revenue effect, speed superiority, general reliability rate, or final brand release follows from this pilot.
