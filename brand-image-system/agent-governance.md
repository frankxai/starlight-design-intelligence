# Agent Governance

This file prevents future agents from creating conflicting brand image systems.

## Source-Of-Truth Order

1. Repo-local `AGENTS.md` and estate `AGENTS.md`.
2. `agentic-ops-hub` for brand operating units, Slack channels, approval gates, repo ownership, and portfolio routing.
3. `starlight-design-intelligence` for brand packs, design intelligence, generated asset gates, and this image system.
4. `design-agent-standards` for asset tiers, design loop, and outcome scoring.
5. Repo-local brand files when a central pack is missing or more specific.
6. `C:\Users\frank\brands\image-system` for working assets, local logs, trackers, and generated outputs.

If sources disagree, do not overwrite. Record the conflict in the local job log and propose a change to the canonical file.

## Agent Start Contract

For cross-brand visual/media/social work, future agents must:

1. Classify the task by brand operating unit before creating assets.
2. Load the relevant brand source listed in `source-map.md`.
3. Choose the channel using `social-channel-matrix.csv`.
4. Choose the source method using `tool-benchmark-plan.md`.
5. Declare asset tier before production.
6. Store prompts, outputs, and inspection notes in the local mirror.
7. Score actual exports with the 30 point gate.
8. Require `#social-approvals` before publishing or scheduling.

## No-Override Rules

- Do not create a new brand-image-system folder in another random repo.
- Do not treat the local mirror as canonical strategy.
- Do not claim a generated image succeeded unless an actual output path exists.
- Do not use Hermes for image generation until its backend and first output path are verified.
- Do not generate exact text, numbers, diagrams, charts, code, or UI inside image pixels.
- Do not ship Tier D decorative filler as a primary asset.
- Do not blend Arcanea mythic language into FrankX, Starlight, or enterprise surfaces without explicit request.
- Do not use AnimeLegends mascots, names, sigils, or lore as generic GenCreator assets.

## Compliance Test

An agent is compliant if its handoff includes:

- Brand operating unit.
- Channel and dimensions.
- Brand source read.
- Tool/source method.
- Prompt or capture route.
- Output path.
- Inspection result.
- 30 point score.
- Approval route.
- Known gaps.

Missing any of these means the visual loop is incomplete.

## Human Escalation

Escalate to Frank before:

- Publishing or scheduling social posts.
- Changing public brand positioning.
- Promoting an incubator lane into a brand.
- Replacing a brand pack.
- Using external or unclear-rights assets in public brand surfaces.
- Shipping assets with medical, financial, legal, investment, or other high-stakes claims.
