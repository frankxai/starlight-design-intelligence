# Design Agent Operating System

This repo is the owned design-intelligence layer. Public curation belongs in `awesome-design-agent-skills`; reusable skill packaging belongs in `design-agent-skills`; canonical standards belong in `design-agent-standards`.

`starlight-design-agent-skills` is the executable companion repo. Keep both: this repo owns brand intelligence, while the skills repo owns runtime hooks, brand routing, and evidence templates.

## Core Loop

For any Starlight, FrankX, Arcanea, Agentic Income, or partner visual task:

1. Read the workspace Design Taste Kernel.
2. Read `design-agent-standards/PREMIUM_ASSET_STANDARD.md`.
3. Read `design-agent-standards/OUTCOMES.md`.
4. Read `design-agent-standards/AGENTIC_DESIGN_LOOP.md`.
5. Load the relevant brand pack from this repo.
6. Choose asset tier and source method.
7. Research current references if the work touches trends, tooling, platform crops, motion, or public brand comparison.
8. Produce a direction board: Keep, Avoid, Signature, System, Sources.
9. Generate, code, animate, capture, or design with the correct tool.
10. Inspect the actual output.
11. Score with `evals/generated-asset-quality-gate.md`.
12. Iterate or restart until it clears the gate.

## Brand Roles

- FrankX: creator command, credible acceleration, product evidence, sharp personal brand systems.
- Starlight: calm operational intelligence, systems, trust, clarity, dashboards, governance, evidence.
- Arcanea: mythic creative intelligence, worlds, ritual, cinematic studio surfaces, creator magic.
- Agentic Income: pragmatic conversion, trusted tools, network proof, fast path from attention to action.

## Tool Choices

- Code exact text, charts, diagrams, UI screens, and data.
- Generate cinematic frames, campaign imagery, world scenes, and exploratory mood.
- Edit from a base image for consistent characters, objects, screenshots, or compositions.
- Build logos as vector first; create 3D renders only after the mark works.
- Use GSAP/Motion/Remotion/Lottie when motion communicates a clear purpose.
- Block Tier D decorative filler as the primary asset for premium surfaces.

## Prompt And Infographic Integrity

For generated imagery, load `brand-image-system/standards/PREMIUM_IMAGE_PROMPT_STANDARD.md` and create a prompt packet rather than storing only the final prompt string.

For infographics, diagrams, charts, architecture plates, comparisons, or timelines:

1. Build a sourced claim ledger and semantic model before visual production.
2. Let generated imagery carry only the declared illustration or draft-composition role.
3. Render final copy, data, edges, citations, and canonical marks deterministically.
4. Run semantic review before visual review.
5. Provide a short alternative and an equivalent long description.

Use `brand-image-system/standards/PREMIUM_INFOGRAPHIC_STANDARD.md` for the full gate and `brand-image-system/standards/INFOGENIUS_ADAPTER.md` when Infogenius is the producer. Arcanea Gate styling is an optional brand layer; it never overrides the universal semantic contract.

## Handoff Standard

Every serious visual handoff should include:

- Outcome contract.
- Direction board.
- Source links or local standards used.
- Prompt packet and actual model/source receipt when generation is used.
- Claim ledger, semantic model, and long description when the asset is an infographic or other complex image.
- Asset list.
- QA score.
- Separate semantic and visual verdicts for information-bearing assets.
- Known limitations or next iteration.
