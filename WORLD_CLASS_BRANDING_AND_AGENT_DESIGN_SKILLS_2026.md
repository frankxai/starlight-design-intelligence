## Standard Operating Procedure: End-to-End Brand Creation

When creating a new brand identity, logo, or design system:

1. **Phase 1: Research & Trend Benchmarking (Grok + Antigravity)**
   - Run `xpoz-intelligence` to benchmark competitor visuals and visual hooks.
   - Generate mood boards and direction boards using Antigravity `generate_image`.

2. **Phase 2: Token & Style Specification (Claude Code)**
   - Load design tokens from `design-tokens.yaml` or create a new brand pack in `starlight-design-intelligence/brand-packs/`.
   - Define HSL color palettes, 2 font choices (Display + Body), spacing scale, and radius system.

3. **Phase 3: Vector Mark / Logo Creation (Claude Code / Antigravity)**
   - Design vector SVG mark first. Validate monochrome, small favicon, and full lockup scale.
   - Apply 3D or material rendering only after vector mark passes clarity checks.

4. **Phase 4: Component & Page Assembly (Claude Code + Vercel v0)**
   - Build production components using `frontend-design` and `ui-ux-pro-max`.
   - Enforce liquid glass aesthetics, fluid typography, and dynamic hover micro-animations.

5. **Phase 5: Visual QA & Santa Review Loop (Codex + CDP Multiplexer)**
   - Run automated Playwright visual capture via CDP Multiplexer (`http://localhost:9223`).
   - Run 30-point quality evaluation (`evals/generated-asset-quality-gate.md`).
   - Run adversarial code review with Codex (`maker != checker`). Ship only upon consensus.
