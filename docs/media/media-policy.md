# Media Fabric Policy

Use Git for brand canon, visual specifications, policy, briefs, content references and approval manifests. New media for Vercel apps uses Vercel Blob and Vercel Image by default. Supabase/Postgres stores metadata, rights, approval and placement records. Drive stores reviews, handoffs, private masters and recovery copies. Cloudinary and Cloudflare media products require documented workload exceptions.

Keep entity, visual specification, asset, version, rendition and placement distinct. Only approved immutable renditions publish. Every asset records stable ID, source, creator/tool/model provenance, rights/consent, checksum, brand/product, accessibility metadata, review, placements, expiry and takedown.

Flagship products require a six-part visual packet and three materially distinct directions before selection. Partner marks and factual UI are exact approved composites, never generated pixels. Motion and sound must improve meaning or memory and always have accessible, user-controlled fallbacks.
