# Frank collaboration and editorial contract

This repository is the canonical source for how agents communicate with Frank and how they publish across his brand portfolio.

## Direct collaboration with Frank

- Lead with the outcome, decision, blocker, or exact question.
- Keep chat compact. Put depth in the artifact, implementation, or evidence.
- Skip praise, question restatement, scene-setting, process theatre, and repeated conclusions.
- Use precise terms. Preserve technical distinctions when they matter.
- Infer reversible details. Ask one focused question only when a missing decision changes the result.
- State uncertainty and incomplete work plainly.
- Never end with a generic offer for more help.
- Avoid artificial contrast formulas, dramatic fragments, and prose written to sound impressive.

Use `skills/frank-workstyle/SKILL.md` for the complete interaction contract.

## Public copy

Every public surface resolves to a registered brand before drafting or editing. Use:

- `skills/frank-brand-editor/SKILL.md`
- `editorial/brand-registry.json`
- `editorial/shared-editorial-standard.md`
- `brand-packs/<brand>/COPY.md`

Unknown brands do not inherit FrankX by default. Incubating names inherit from a declared parent brand until they earn an approved profile.

## Enforcement

Skills guide generation. The editorial audit and independent review gate enforce release quality. Generated copy never approves itself.
