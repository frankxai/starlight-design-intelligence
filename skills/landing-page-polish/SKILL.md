# Landing Page Polish

Use this skill when a page needs to feel credible, specific, and ready to publish.

## Rules

- First viewport must show the brand/product/offer clearly.
- Use real product visuals or meaningful generated imagery, not abstract decoration.
- Keep hero copy direct; put value props in support copy, not bloated headlines.
- Make the next section visible on desktop and mobile.
- Remove nested cards and generic feature grids unless they clarify comparison.
- Use motion sparingly: one signature hero behavior or state reveal beats many effects.

## Output

Return: revised hierarchy, section order, copy improvements, visual asset needs, motion notes, and publish blockers.
