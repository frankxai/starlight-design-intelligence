# Design System Extractor

Use this skill to turn scattered design evidence into reusable rules.

## Extract

- Foundations: color, typography, spacing, radius, shadow, grid, density.
- Components: buttons, cards, forms, tables, navigation, modals, charts.
- Content: heading style, body copy, labels, empty states, CTAs.
- Motion: transitions, easing, duration, entry/exit, reduced-motion.
- Brand: motifs, imagery, icon style, product-specific rules.

## Output

Return: detected system, missing tokens, component patterns, motion rules, inconsistencies, and implementation recommendations.
