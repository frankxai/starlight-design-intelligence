# Product UI Polish

Use this skill for operational interfaces where users scan, compare, decide, and act repeatedly.

## Rules

- Prioritize task flow over hero-style composition.
- Use dense but organized layouts: clear navigation, compact controls, stable tables, predictable filters.
- Make state visible: loading, empty, error, success, syncing, blocked, complete.
- Keep typography compact and readable; no oversized marketing headings inside tools.
- Use icons, segmented controls, toggles, sliders, and menus where they match the job.
- Motion should confirm actions, reveal relationships, and animate data deltas without slowing operators.

## Output

Return: workflow risks, layout fixes, component/state fixes, density improvements, motion notes, and acceptance checks.
