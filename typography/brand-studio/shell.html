What this comparison proves

Nine exact upstream font files and seven matching license notices are embedded in this document. No font service, account or network request is required. Each frame has its own real CSS viewport. Text at 200% enlarges the root text size; it is a text-resize stress test, not a claim of browser zoom testing. Fallback mode removes font-face declarations from the specimen frame. The chrome remains system type.

The copy and structure stay identical when a pairing changes. Arcanea compares a Newsreader reading surface with a Geist reading surface and short Instrument Serif display. Each uses two families. Symbols are drawn as SVG where a font has no arrow. The work contains original specimen copy and geometric layout elements, not newly approved logos, customer claims or production screenshots.
