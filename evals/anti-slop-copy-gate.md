# Anti-Slop Public Copy Gate

The content-addressed public-copy artifact for a flagship release must not contain
empty technology-superlative language. The release validator rejects these phrases:

- AI-powered
- next-gen / next generation
- game-changing
- revolutionary
- hyper-personalized
- future-forward
- cutting-edge
- seamless / seamlessly
- world-class

This is deliberately narrow. It does **not** scan research, source evidence,
quotations, code, technical documentation, or internal notes. It scans only the
reviewed public-copy artifact named in the release receipt.

Use concrete behavior, a named recipient, verified proof, and an honest next action
instead. If a technical capability matters, describe the actual capability and its
observable consequence rather than applying a generic label.
