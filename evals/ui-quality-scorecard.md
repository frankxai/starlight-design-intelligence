# UI Quality Scorecard

Score 0-3 for each item.

- Purpose: user can identify the job of the screen.
- Hierarchy: primary action and key information are obvious.
- Layout: spacing, grouping, and alignment are stable.
- Density: information density matches the workflow.
- Typography: readable, consistent, no oversized tool headings.
- Color: purposeful contrast and state use.
- Components: controls match familiar interaction patterns.
- States: loading, empty, error, success, disabled, active.
- Motion: useful, interruptible, reduced-motion safe.
- Accessibility: contrast, focus, keyboard, reduced motion.
- Brand fit: visual and copy choices match the intended brand.
- Implementation readiness: can be built without guessing.

0-18: not ready. 19-27: usable with fixes. 28-36: strong.
