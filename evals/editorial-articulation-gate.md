# Editorial Articulation Gate

Score each item 0, 1, or 2. Release requires **18/20** and no automatic failure.

| Item | Passing evidence |
| --- | --- |
| Recipient reality | Exact person or buying moment is legible |
| Observed truth | A real moment, artifact, behavior, quote, or result |
| Proposition | Smallest credible next move is explicit |
| First 120 words | Why, observation, proposition, and reason to continue |
| Sentence craft | Human cadence, concrete nouns, active verbs |
| Taxonomy restraint | Builder language follows value and proof |
| Proof adjacency | Evidence sits next to each important claim |
| Voice | Frank could say it aloud without embarrassment |
| Deletion discipline | No grand line survives without carrying meaning |
| Independent read | Non-author identifies recipient and proposition precisely |

Automatic failure: invented quotation or endorsement, simulated intimacy,
recipient-name-swappable praise, architecture before relationship, false
inevitability, or a CTA disguising a sales script as generosity.
