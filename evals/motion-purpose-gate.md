# Motion Purpose Gate

Score each item 0, 1, or 2. Shipped motion requires **16/18**.

| Item | Passing evidence |
| --- | --- |
| Job | Names orientation, hierarchy, causality, state, explanation, progress, spatial relationship, or memory |
| Static foundation | Complete experience exists without motion |
| Choreography | Setup, action, resolution, and stable anchor are clear |
| Control | Interaction is responsive and interruptible |
| Restraint | One signature sequence; secondary motion is causal |
| Mobile | Mobile choreography is intentionally re-composed |
| Reduced motion | Designed equivalent retains information and hierarchy |
| Performance | Runtime evidence shows stable scroll and input |
| Brand memory | Sequence demonstrates the proposition rather than decoration |

“Premium,” “cinematic,” and “delight” are emotional targets, not jobs. If the
reviewer cannot say what motion makes easier to understand or remember, cut it.
