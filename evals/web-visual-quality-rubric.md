# Web Visual Quality Rubric

This is the 30-point visual rubric referenced by flagship web release evidence.
Score each category 0–5. Release requires **28/30** and may still be blocked by the
independent verifier.

| Category | 0 | 3 | 5 |
| --- | --- | --- | --- |
| Recipient fit | Generic or misaddressed | Broadly relevant | Could only belong to this recipient and job |
| Composition | Accidental or template-led | Clear hierarchy | Authored, memorable hierarchy with disciplined pacing |
| Typography | Default, unresolved, or fragile | Competent system | Voice, hierarchy, loading, and responsive wraps are exact |
| Evidence | Claims or decorative proof | Some real artifacts | Proof drives the composition and sits beside each claim |
| Responsive craft | Desktop compressed into mobile | Usable reflow | Desktop and mobile are deliberately distinct compositions |
| Distinctiveness | Could be any AI site | On-brand | Ownable behavior and visual memory without relying on a logo |

Automatic failure:

- slogan-only first viewport;
- repeated equal-weight card wall on an editorial or relationship surface;
- invented or synthetic recipient evidence;
- unresolved font family;
- proof that consists only of repo names, diagrams, or technology labels;
- mobile screenshots absent or merely stacked;
- a score supplied by the maker without independent visual inspection.
